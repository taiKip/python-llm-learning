# Python LLM Learning

Python fundamentals through to LLM API integration — built alongside COMP6012 Large Language Models and Applications at Adelaide University.

## Structure
- `src/day1_basics/` — variables, types, strings, lists, dicts
- `src/day2_functions/` — functions, error handling, modules
- `src/day3_apis/` — HTTP requests, JSON, REST APIs
- `src/day4_llm/` — LLM API calls, prompt engineering, structured outputs
- `tests/` — pytest test suite
- `notebooks/` — Jupyter experiments

## Setup
```bash
pip install -r requirements.txt
```

## Run tests
```bash
pytest tests/ -v
```
